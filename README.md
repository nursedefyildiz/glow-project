# Glow ✨ | Personal Interactive Dashboard

**Glow**, geleneksel kişisel web sitelerine modern ve eğlenceli bir alternatif olarak tasarlanmış, **Pixel-Art** estetiğine sahip interaktif bir web deneyimidir. 

Bu proje, bir mühendislik öğrencisinin web teknolojileri (HTML, CSS, JS) üzerindeki gelişim sürecini ve kullanıcı deneyimi (UX) konusundaki vizyonunu yansıtmak amacıyla geliştirilmektedir.

## 🌟 Öne Çıkan Özellikler

- **Pixel-Art Estetiği:** Retro oyun dünyasından esinlenen, keskin hatlı ve karakteristik görsel tasarım.
- **Interaktif Menü:** Kullanıcıyı yormayan, emoji destekli ve pikselli animasyonlarla güçlendirilmiş navigasyon.
- **Şans Kurabiyesi:** Rastgele veri çekme mantığıyla çalışan mini-oyun entegrasyonu.
- **Mobil Uyumlu (Responsive):** Farklı ekran boyutlarında (özellikle mobil) pürüzsüz çalışma deneyimi.

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Yapısal kurgu ve içerik hiyerarşisi.
- **CSS3:** Glassmorphism efektleri, pikselli gölgeler ve özel animasyonlar.
- **JavaScript (Vanilla):** Dinamik içerik yönetimi ve sayfa yönlendirmeleri.
